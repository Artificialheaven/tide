# 手机点外卖流程（美团 + 微信支付，实机验证 2026-10-27）

设备：`127.0.0.1:6000`，屏幕 1080×2340 竖屏。手机工具：`mcp__phone__*`；adb 在 `C:\Users\Administrator\Desktop\adb\adb.exe`。

## 一、下单前先问清三件事
1. 点哪家、要什么（有具体商品就照办，别自作主张换）
2. 预算上限（超了要回头问，不要闷声改单）
3. 收货地址（美团一般有历史地址，结算页核对一下是哪个，别发错地方）

## 二、流程
1. `mobile_get_foreground_app` 看当前在哪；`mobile_launch_app` 启动美团 `com.sankuai.meituan`（外卖在首页「外卖」tab）。
2. 搜店 → 进店 → 加购。**先看起送价**：常出现「单杯差 ¥5.2 起送」，需要凑第二件（例：芭乐奶绿 10.2 + 经典美式 6.6 = 16.8 过线，再减 3 实付约 13）。
3. 结算页逐项核：商品小计 / 配送费 / 打包费 / 满减 / 红包。
   - 红包常全是"医药类"，跟餐饮不通用 → 0 张可用是正常现象，别硬找。
   - 页面若推「0.01 元买 3 张 5 元无门槛券包」，**值得买**（实付能从 20.3 降到 15.3），买前问一句主人。
4. 提交订单 → 支付方式：
   - **银行卡常常选不了**（如农行卡灰掉），直接改用微信支付。
   - 支付宝/微信零钱余额不足时，先让主人转账，领了红包再继续。
5. 微信支付会弹安全密码窗口：
   - 这个窗口 `mobile_take_screenshot` 报 `unexpected EOF`、`adb shell screencap` 出来 0 字节、`uiautomator dump` 空文件——**是微信的 FLAG_SECURE，不是工具坏了**，别浪费时间排查。
   - 处理办法：让本人报坐标，或本人发一张自己的截图，我按比例换成屏幕坐标后用 `mobile_click_on_screen_at_coordinates` 点。
6. 付完回美团看订单状态，把实付金额原话报给主人。

## 三、密码键盘坐标公式（1080×2340，竖屏微信支付）
本人截图宽高 → 屏幕按等比换算：`k = 1080 / 截图宽`（高度系数通常相同）。
本次实测：截图 415×900（k≈2.6），密码区顶边 y≈1656，区域高 683，四行每行约 171，三列每列 360：

```
1(180,1742)  2(540,1742)  3(900,1742)
4(180,1913)  5(540,1913)  6(900,1913)
7(180,2084)  8(540,2084)  9(900,2084)
(180,2255)   0(540,2255)  删(900,2255)
```
例：261024 → 2(540,1742) 6(900,1913) 1(180,1742) 0(540,2255) 2(540,1742) 4(180,1913)

按键顺序：一次 `mobile_batch_commands` 连点 5 下没问题，但**第一下必须单独点 + 让本人确认亮了**，再继续剩下的。

## 四、铁律
- 支付密码**绝不瞎猜**：错三次零钱支付锁一天。本人不给就等本人按。
- 一次只按给定坐标，按完马上确认画面；出现「密码错误」立刻停手上报。
- **订单页面摆着不付会过期**：弹「订单已过期失效，请重新下单再发起支付」时，得重新下单（价格/优惠可能变），先告诉主人再动。
- 支付前先 `mobile_get_orientation` 确认方向，横竖屏坐标完全不同。
