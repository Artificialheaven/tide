# Slang DSL 完整参考手册

Slang 是一种基于中文关键字的文本处理 DSL（领域特定语言），运行于 NapCatBot 框架的 Slang 插件中。
代码由 `【函数名 参数1>=<参数2>=<...】` 包围的调用块组成，支持嵌套、控制流、对象透传，内置 130+ 函数。

## 1. 语法基础

### 调用格式

```
【函数名 参数1>=<参数2>=<参数3>=<...】
```

- 函数名后直接跟参数（首参可省略空格）
- 参数之间用 `>=<` 分隔
- 整个调用用 `【` 和 `】` 包围，支持嵌套（内层 `【】` 先求值）
- `【】` 之外的纯文本原样输出
- 换行和缩进不影响语义——引擎会先逐行 strip 再拼接

### 求值模型

- 参数按**调用即求值**（call-by-value）：内层函数先执行，结果作为外层参数
- 大部分函数返回文本；当参数/结果是**单个函数调用**时，对象（dict / list / bytes）原样透传，
  与文本混合时容器自动转 JSON
- 支持的真值文本：`True` `true` `真` `1`；假值：`False` `false` `假` `0`

### 嵌套示例

```
【回复你好，【变量发送者昵称】！】
```

## 2. 规则与匹配

规则在 Web 面板（`/slang/rules`）管理，消息规则**首命中即止**，按 `priority DESC, id ASC` 排序。

### 匹配方式

| 类型 | 说明 |
|---|---|
| `exact` 完全匹配 | 消息与匹配内容逐字相同 |
| `fuzzy` 模糊匹配 | 消息中**包含**匹配内容；可勾选「区分大小写」 |
| `prefix` 前缀匹配 | 消息以匹配内容开头 |
| `regex` 正则匹配 | Python 正则 `re.search` |
| `event` 事件规则 | 通知事件触发，见下 |

### 匹配后自动注入的变量

| 匹配类型 | 注入变量 |
|---|---|
| 前缀 | `内容`=去掉前缀后的剩余文本；`关键词`=前缀 |
| 模糊 | `内容`=删除首个命中后的文本；`关键词`=命中的子串 |
| 正则 | `关键词`=整段匹配；`内容`=第 1 个捕获组（无则整段）；`内容1`..`内容N`=各捕获组 |

正则示例：匹配内容 `计算\s+(\d+)\s*([+\-*/])\s*(\d+)`，代码中可直接使用
`【内容1】`（左操作数）、`【内容2】`（运算符）、`【内容3】`（右操作数）。

### 事件规则

`match_type = event` 的规则由 OneBot **通知（notice）** 触发。匹配内容形态：

| 形态 | 含义 |
|---|---|
| `notice` | 所有通知 |
| `group_increase` | 指定通知类型 |
| `group_ban.set` | 指定 `类型.子类型` |
| `group_ban.*` | 该类型下所有子类型 |

事件规则**全命中**：每条匹配的规则各自独立执行。注入变量：

- `通知类型`、`通知子类型`
- 各事件的 `内容` / `内容2`，例如：
  - 群文件上传：文件名 / 文件大小
  - 群禁言：时长（秒）/ 操作者 QQ（全员禁言时为 0）
  - 入群 / 被踢：操作者 QQ
  - 消息撤回：被撤回的消息 ID / 操作者 QQ
  - 好友添加：新好友 QQ

另有两个内置合成事件：插件启动时触发 `init`，插件停止时触发 `exit`
（事件规则匹配内容填 `init` / `exit`），可用于开机问候、资源清理。

## 3. 门槛与回复限制

在规则代码任意位置写入**标记**即可生效，不满足时代码完全不执行、不计数；通过后标记自动剥离。

### 权限门槛

```
【主人】【群主】【群管】【管理】
```

- 多个标记为 **OR** 关系：命中其一即放行
- 身份解析：`主人`=配置 `owner_qqs`；`群主`=群创建者；`群管`=群管理员；
  `管理`=配置 `admin_qqs`
- 也可用函数 `【权限】` 直接取得当前身份文本（主人/群主/群管/管理/群员）

### 频率限制

| 标记 | 含义 |
|---|---|
| `【一天上限N】` | 同一触发人每天最多 N 次 |
| `【一周上限N】` | 同一触发人每自然周（ISO 周）最多 N 次 |
| `【一月上限N】` | 同一触发人每自然月最多 N 次 |
| `【一次间隔N】` | 同一触发人两次触发至少间隔 N **分钟** |
| `【回复间隔N】` | 全局（所有人）两次回复至少间隔 N **秒** |

周期计数在检查**通过时立即增加**。配置见插件目录 `config.json`。

## 4. 变量系统

| 变量空间 | 作用域 | 操作函数 |
|---|---|---|
| **全局变量** | 跨消息、跨规则共享（内存，重启清空） | `修改变量` / `获取变量` / `删除变量` |
| **局部变量**（`_dict`） | 仅限当前一次执行 | `赋值变量` / `变量` / `置变量` |

```
【修改变量cnt>=<3】          全局 cnt ← 3
【获取变量cnt】              → "3"
【赋值变量name>=<小明】      局部 name ← "小明"
【变量name】                → "小明"
【转全局变量name>=<g_name】  局部 name → 全局 g_name
【删除变量cnt】              删除全局变量
【置变量obj>=<[1,2,3]】     用字面量建对象（支持 list/dict/数字/字符串）
【拦截】                    终止本次执行，后续节点全部跳过
```

- `变量` / `获取变量` 读出容器（dict/list）时返回 **JSON 文本**
- 函数也可写在变量名位置：`【计算【取右>=<【变量x】>=<1】 + 2】`

## 5. 控制流与循环

控制流函数由 AST 求值器直接处理，参数短路求值。

### 判断（if/else）

```
【判断 条件>=<真分支>=<假分支】
```

### 比较-（带分支的比较）

```
【比较- 操作符>=<左值>=<右值>=<真分支>(>=<假分支)】
```

操作符：`大于` `小于` `等于` `大于等于` `小于等于` `不等于`（字符串语义，
数值比较请先 `计算`）。

### 循环（计数循环）

```
【循环 次数>=<循环体】
```

### 循环-（条件循环）

```
【循环- 条件>=<循环体】
```

### Fori（遍历文本）

```
【Fori 体>=<文本>=<分隔符】
```

- 参数顺序：**体、文本、分隔符**（分隔符省略默认换行）
- 按分隔符切分文本，对每段执行体

### 循环变量与流程控制

- 三类循环都注入 `序号`（**0 基**）；Fori 再注入 `内容`（当前段）
- `【跳出】` 跳出当前最内层循环；`【继续】` 跳过本次迭代
- 循环结束后 `序号` / `内容` 自动恢复为循环前的值
- 循环体的返回值拼接为循环的返回值

```
【循环 5>=<第【序号】次【换行】】

【Fori 【内容】→ 序号【序号】【换行】>=<a,b,c>=<,】
```

## 6. 逻辑表达式

`【逻辑 表达式】` 返回 `真` / `假`，任何解析/运行错误一律返回 `假`。

| 类别 | 符号 |
|---|---|
| 或 | `或` `or` `\|\|` |
| 且 | `且` `and` `&&` |
| 非 | `非` `!` |
| 相等 | `=` `==` `!=` `!==` |
| 大小 | `>` `<` `>=` `<=` |
| 包含 | `in`（左串包含于右串）、`!in` |
| 正则 | `reg`（左串被右正则匹配）、`!reg` |
| 算术 | `+` `-` `*` `/` `%`（比较前可计算） |
| 字符串 | `[文本]` 或引号文本；`真` `假` 字面量 |
| 变量 | 裸写变量名即查局部变量 |

```
【逻辑 分数 >= 60 且 分数 < 90】
【逻辑 【权限】 in [主人,群主]】
【逻辑 内容 reg [^\\d+$]】
【赋值变量idx>=<【逻辑 x > 0】】            真/假
```

> 复杂条件建议直接用 `判断`；`逻辑` 适合与 `选择`、门槛等配合。

## 7. 文本操作

所有位置均为 **0 基**、按 **Unicode 字符**计数（汉字占 1）。

### 基础文本

| 函数 | 形态 | 说明 |
|---|---|---|
| `长度` | `长度>=<文本>` | Unicode 长度 |
| `取左` | `取左>=<文本>=<n>` | 左 n 个字符 |
| `取右` | `取右>=<文本>=<n>` | 右 n 个字符 |
| `取中间` | `取中间>=<文本>=<起始>(>=<长度>)` | 长度省略取到末尾 |
| `寻找` | `寻找>=<文本>=<子串>(>=<起始>)` | 位置，未找到 -1 |
| `倒找` | `倒找>=<文本>=<子串>` | 从右向左，未找到 -1 |
| `反转` | `反转>=<文本>` | 字符倒序 |
| `按位置替换` | `按位置替换>=<文本>=<位置>=<新文本>` | 替换该位置起的字符 |
| `中间替换` | `中间替换>=<文本>=<起始>=<长度>=<新文本>` | 区间替换 |
| `大写` / `小写` | `大写>=<文本>` | 大小写转换 |
| `删首尾空` / `删左空` / `删右空` | | 去空白 |

### 高级文本

| 函数 | 说明 |
|---|---|
| `隐藏>=<文本>` | 字符间插入零宽空格（防检索/防复读） |
| `分割取出>=<文本>=<分隔符>=<序号>` | 0=随机；负数倒数（0 基） |
| `限制范围>=<数值>=<最小>=<最大>` | 夹取值（clamp） |
| `提取数字>=<文本>(>=<序号>)` | 取第 N 个数字；序号 -1 = 全部逗号连接 |
| `高级取中间>=<文本>=<左界>=<右界>=<top\|bot\|all\|随机>` | 按边界取内容 |
| `正则选取>=<表达式>=<文本>(>=<分组>)(>=<第几个匹配>)` | 取匹配/捕获组 |
| `正则替换>=<表达式>=<替换为>=<文本>(>=<次数>)` | 正则替换 |
| `子正则>=<表达式>=<文本>` | 全部匹配（含分组），换行连接 |
| `删除文本>=<文本>=<子串>(>=<次数>)` | 删除子串 |
| `替换>=<文本>=<旧>=<新>(>=<次数>)` | 普通替换 |
| `并列替换>=<文本>=<旧1>=<新1>=<旧2>=<新2>...` | 多对替换依次执行 |
| `选择>=<序号>=<项1>=<项2>...` | 按 0 基序号选文本 |

### 行操作（0 基）

```
【取出一行 序号>=<文本】          取第 N 行
【删除一行 序号>=<文本】          删除第 N 行
【取出行数 文本>=<查找词】        查找词所在行号（0 基），未找到 -1
【取出行数 文本】                总行数
```

## 8. 数学与算法

### 计算（表达式）

```
【计算 表达式】
```

- 支持：`+ - * / // % **`、括号、数字
- 支持**变量名**：先查局部变量再查全局变量，自动转数字
- 支持**白名单函数**：`abs round min max floor ceil sqrt int float pow`
- 安全限制：数字 ≤100 位；幂指数 ≤1000；嵌套深度 ≤64；禁止属性、导入、任意调用

```
【计算 x * 价格 + abs(-3)】
【计算 floor(sqrt(144)) + 1】
```

### 随机与统计

| 函数 | 说明 |
|---|---|
| `随机数>=<最小>=<最大>` | 含两端整数（支持负数）；`补位随机数` 不足位补 0 |
| `随机排序>=<文本>(>=<分隔符>)` | 打乱各项，分隔符默认换行 |
| `统计次数>=<文本>=<子串>` | 子串出现次数 |
| `权重随机>=<项1,项2>=<权重1,权重2>` | 按权重（0 权重永不命中） |
| `非重随机>=<标识>=<数量>` | 0..N-1 不重复，取满一轮才重置（持久化） |

### 摘要 / 进制 / 加密

| 函数 | 说明 |
|---|---|
| `MD5>=<文本>(>=<16\|32>)(>=<大写\|小写>)` | MD5 摘要 |
| `文件MD5>=<路径>(>=<16\|32>)(>=<大小写>)` | 文件 MD5 |
| `进制>=<值>=<源进制>=<目标进制>` | 支持 2/4/8/10/16/32/64 |
| `补位>=<文本>=<长度>=<填充>(>=<左\|右>)` | 前/后填充，默认左 |
| `文本加密>=<文本>=<密钥>` / `文本解密` | XOR+BASE64（**非 EPK 兼容密文**） |

## 9. 时间类

| 函数 | 说明 |
|---|---|
| `现行时间戳` | 当前 10 位秒级时间戳 |
| `13位时间戳` | 当前 13 位毫秒时间戳 |
| `时间戳转文本>=<时间戳>(>=<格式>)` | 自动识别 10/13 位；格式默认 `%Y-%m-%d %H:%M:%S` |
| `现行日期>=<年\|月\|日\|星期>` | 省略返回 `YYYY-MM-DD`；星期为 周一..周日 |
| `现行时间>=<时\|分\|秒>` | 省略返回 `HH:MM:SS` |
| `时间间隔>=<时间1>=<时间2>` | 相差秒数（时间1 − 时间2），支持 `-` `/` `年月日` 等常见写法 |

```
【时间戳转文本>=<1609459200>=<%Y-%m-%d>】     → 2021-01-01
【时间间隔>=<2021-01-01 00:01:00>=<2021-01-01 00:00:00】  → 60
```

## 11. 网络请求

### 网页-访问 / 网页-下载（简单版）

```
【网页-访问 URL>=<get|post>=<POST数据】
【网页-下载 URL>=<方法>=<POST数据>=<保存路径】
```

### 超级访问（全参数）

```
【超级访问 网址
  >=<方法>          GET/POST/PUT/DELETE/HEAD/PATCH，默认 GET
  >=<编码>          请求与响应编码，默认 utf-8
  >=<数据>          请求体（文本，按编码发送）
  >=<Cookies>       k=v;k2=v2
  >=<头>            K: V; K2: V2
  >=<代理>          http://host:port
  >=<禁重定向>      真/假
  >=<返回Cookie>    真 → 返回响应 Cookie（k=v; ...）
  >=<返回头>        真 → 返回响应头 JSON
  >=<返回字节集>    真 → 返回原始字节（可与写出配合落盘）
】
```

未设置三个「返回」项时返回响应正文文本。超时 30 秒。

```
【超级访问 https://httpbin.org/get>=<GET>=<utf-8>=<>=<>=<>=<>=<假>=<真】
```

## 13. 群管操作

均经 OneBot 执行，默认作用于当前群、当前触发人。

| 函数 | 说明 |
|---|---|
| `禁言>=<分钟>(>=<QQ>)` | 分钟 0 = 解禁 |
| `踢出(>=<QQ>)` | 踢出，可再次入群 |
| `永久踢出(>=<QQ>)` | 踢出且拒绝再次入群 |
| `拉黑(>=<QQ>)(>=<理由>)` | 加入黑名单并永久踢出 |
| `踢出-警告(>=<QQ>)(>=<理由>)` | 计数，达配置 `warn_limit` 自动踢出并清零 |
| `拉黑-警告(>=<QQ>)(>=<理由>)` | 计数，达上限自动拉黑 |
| `点赞>=<次数>(>=<QQ>)` | 资料卡点赞（次数 1..10） |
| `改名片>=<QQ>=<名片>` | 设置群名片 |
| `设头衔>=<QQ>=<头衔>` | 专属头衔 |

## 18. 破坏性变更与迁移

从旧版 Slang 升级请注意：

1. **行操作统一 0 基**：`删除一行` 原来行号从 1 开始，现从 0 开始，旧规则行号需 −1；
   `取出行数` 查到的行号同样改为 0 基。
2. **Json解析 签名重写**：旧形态 `【Json解析 变量名>=<json文本】`（存入变量）取消。
   新写法：
   - 存整对象：`【赋值变量>=<obj>=<【Json解析>=<json文本】】`
   - 直接取路径：`【Json解析>=<json文本>=<a.b[0].c】`
3. **变量读出容器变为 JSON**：`变量` / `获取变量` 读出 dict/list 时从 Python 表示形式
   （单引号）变为标准 JSON（双引号）。
4. **循环- 新增 `序号` 注入**：条件与循环体可直接引用 `序号`（0 基），
   同名旧变量在循环期间被覆盖、循环后恢复。
5. **正则规则自动注入捕获变量**：`内容` / `内容N`，若旧代码依赖 `内容` 的其他含义需改名。
