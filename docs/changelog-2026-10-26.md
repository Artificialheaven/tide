## 1. 心情 · 自我记忆 · 主动搭话（上午）

完整文档见 [`mood-self-memory-speakup-guide.md`](mood-self-memory-speakup-guide.md)，要点：

- **心情**：每群一份，心情值基线 70 + 七绪（开心/踏实/甜蜜/心疼/担心/难过/吃醋），
  每次她实际发言后异步跑一次便宜模型判定，显著变化最多在下一轮注入一次"心情背景"句。
- **自我记忆**：关于"我"的第一人称记忆，**全局一份跨所有群/私聊共享**，
  搭车现有记忆抽取，不额外花模型调用。
- **主动搭话**：在原 30 分钟防假死苏醒之上叠加一层掷骰——谷时（夜间/周末/冷场久）
  概率高、刚聊过有自我冷却、安静段（默认 01:00–08:00）不打扰，不想说话就回 `[静默]`。

## 2. 动态工具提示词注入

**问题**：原来工具说明是一段写死的文字，群里关掉的工具、后来沉淀的自定义技能，
模型照样看得到介绍，容易"被引导"去调一个本群不可用的工具。

**做法**（`Core/prompts.py::build_catalog`）：

- 每轮按**本群实际启用的工具集**（群工具开关 + AI 自定义工具 + MCP）动态生成
  中文分组目录：发消息 / QQ 文件 / 聊天记录解读 / 工作区文件 / 群友记忆 /
  你自己的记忆 / 约定待办 / 定时任务 / 自我轮询 / 网页监测 / QQ 空间 /
  执行代码 / 提示词注入表 / 自定义工具沉淀等。
- 关闭的工具**绝不出现**在提示词里；自定义技能自动追加一行
  「名字 —— 一句话描述（仅主人可触发时带标注）」。
- 开头是固定的【工具使用要点】："普通聊天直接回复，不要为了用工具而用工具"，
  结尾是风险操作规则（只有主人 QQ 能指令，认 QQ 号不认昵称）；
  MCP 远程桌面规范仅在本群启用了 MCP 工具时注入。

## 3. 系统提示词编辑页 + PHI

新页面：deepseek Web 面板导航 → **「提示词」**（`/deepseek/prompts`）。

### 能改什么

框架**每轮自动注入的全部系统级文案**都登记在 `Core/prompts.py` 的注册表里，
按五组展示：对话规则 / 富媒体 / 工具 / 上下文块 / 后台触发，共 16 条，包括：

- 身份与聊天规则、`[nospeak]` 内心戏约定、图片附件转发阅读规则、CQ 码禁令
- 工具目录与使用要点、MCP 操作规范
- 当前时间行、摘要/风格/心情/自我记忆/背景消息/本群身份等各块的抬头与包装
- 主动搭话、定时苏醒两种后台触发通知的全文

### 行为约定

- 改完**保存即对后续对话生效，不需要重启**（`PromptStore` 缓存保存时自动失效）。
- 覆盖存在 SQLite `prompt_overrides` 表（迁移 v13）；「恢复默认」= 删掉覆盖。
- `{占位符}` 由系统替换，页面上以 chip 标出，文案里随手写的其他花括号不会报错。
- 绿色边框 = 该条已被覆盖；可折叠查看内置默认文案做对照。
- 单条上限 8000 字。

### PHI（历史前指令，key=`phi`）

一条特殊注册项：**默认留空 = 不注入**。填写后以 `system` 身份插在

> 用户信息（记忆/自我记忆/本群身份/背景/心情/当前时间行）**之后**
> —— 对话历史**之前**

- 只组装进当轮模型请求，**不落库、不进她自己的历史**，摘要/记忆语料里也不存在；
- 每轮（含后台苏醒/搭话轮）都注入，适合放临时强指令，不用了清空即可。

## 4. @全体成员 · 身份感知 · 时间前缀治理

### 4.1 新工具 `qq_at_all`（@全体成员）

- 发送 `[CQ:at,qq=all]`，可附带一条通知正文（≤500 字）同条发出。
- **双门禁**：属于风险工具，只有主人 QQ 能指令（非主人引擎层直接拒绝）；
  运行时再查她自己在本群的角色——不是管理员/群主则返回错误并明确告知
  「不要重试、不要改写 @所有人」。
- 正文里随手写的 `@所有人` 仍不会转真艾特（防止普通群友一句话骗出全员通知）。
- QQ 对 @全体成员每日次数有限，工具说明里也提示了"非必要不用"。
- 可在群工具开关里单独关闭（key `qq.at_all`）。

### 4.2 群成员身份感知

- 新增 `MemberInfoDirectory`（`Core/mentions.py`）：走 OneBot
  `get_group_member_info`，按 (群, QQ) 缓存 10 分钟，失败 60 秒退避，
  任何异常只返回 None，不影响正常对话。
- **每轮群聊自动注入【本群身份】块**：发言人 + 本轮被 @ 的人 + 她自己各一行，
  含 群主/管理员/普通成员、群等级、群头衔；她自己那行带能力提示
  （管理员→"可以调用 qq_at_all"；普通成员→"没有权限，别调"）。私聊不注入。
- 新查询工具 `qq_member_info`：填 QQ 查任何人的身份/名片/入群时间/最近发言，
  不填查她自己，支持 `no_cache` 强刷。key `qq.member_info`，可在群工具页关闭。

### 4.3 回复开头老带时间戳的问题（四层治理）

现象：她经常在回复最前面加 `[10-26 14:30]`、`星期一` 之类的时间。根因与对策：

1. **去掉模仿源**：历史渲染时她**自己的旧回复**以前也被打了行首时间标签，
   等于每轮都在示范"输出要带时间"。现已取消（群友消息的档案时间标签保留）。
2. **独立当前时间行**：对话窗正前方新增一条 system「现在是 YYYY-MM-DD HH:MM
   星期X」，给她准确时间的同时明令"不要在回复开头或正文写日期/星期/时间戳，
   QQ 会自动给消息盖发送时间"。该行在提示词页可改（key=`clock_line`）。
3. **身份规则文案补强**：身份块明确"时间标签是给你看的档案戳，回复不许带"。
4. **出站兜底**：`reply.strip_leading_time` 在发送/落库前剥离开头的时间戳
   （支持 `[10-26 14:30]`、`[14:30]`、裸日期时间等多种样式，叠层也剥）；
   裸"14:30 老地方见"这种正常内容不会误伤，整条只剩时间时保留原文。

## 5. 框架 Web 面板 host/port 可配置

框架管理面板（与 deepseek 插件自己的 :5000 对话展示页不是一回事）：

- `config.json` 新增 `web_admin_host`（默认 `0.0.0.0`），原 `web_admin_port`
  （默认 8081）不变；老配置文件启动时自动补默认值。
- 面板「⚙️ 配置」页可直接改：`0.0.0.0` = 所有网卡（局域网可访问），
  `127.0.0.1` = 仅本机；端口限制 1–65535，非法值后端 400、旧值不变。
- **改后需重启程序生效**（Flask 服务每进程只启动一次），页面标签上有注明。
- 安全提示：监听 `0.0.0.0` 时同局域网可访问登录页，鉴权全靠 token；
  只给自己用时改 `127.0.0.1` 最稳。

## 6. 多初筛脚本（多判官第一层）+ 后台模型提示词可编辑（v2026.10.26.7）

### 6.1 AI 自沉淀的初筛脚本

在「内置启发式粗筛 → LLM 判官」之间插入一层**可由 AI 自己制作的初筛脚本**：

- 契约固定为 `def screen(group_id, user_id, message_raw) -> bool`
  （三个字符串参数；可选第 4 参 `ctx` 字典，声明了才传，不传整个 Message 对象）。
- 触发链是**或门**：非 @ 非回复的群消息，启发式粗筛命中 **或** 任一启用中的
  初筛脚本返回真，才花钱拉起判官；判官判否仍不回复；全部未命中则静默忽略。
- @ 我 / 回复我 / 私聊等强制触发照旧跳过全部闸门。
- 与自定义工具同套安全模型：只在 `python -I` 短生子进程执行，默认 5 秒超时
  杀进程树；validate → publish 流程，坏代码不覆盖旧版；发布/启停/删除仅主人；
  分本群/全局作用域，每作用域默认上限 10；**故障一律按未命中（fail-closed）**。
- 管理工具 5 个：`screen_validate / screen_publish / screen_list /
  screen_toggle / screen_remove`，脚本命中次数、最近命中时间可查；
  群设置新增「AI 初筛脚本」总开关（`screen_on`，可每群关）。
- 完整说明见 [`custom-tools-guide.md`](custom-tools-guide.md) 文末
  「初筛脚本（多判官第一层）」。

### 6.2 判官 / 摘要 / 抽取提示词进提示词页

- 提示词注册表新增「后台模型」分组 3 条：`judge_prompt`（判官）、
  `summary_prompt`（600 字摘要器）、`extract_prompt`（记忆抽取 A/B/C 段），
  Web「提示词」页直接编辑、保存即生效、可恢复默认。
- 页面 hint 明确：**JSON 输出契约必须保留**（判官的 `{"reply": ...}`、
  抽取的 entries/commitments/self_entries），改坏会让对应后台步骤静默失败。
- 不改提示词时行为与此前逐字一致（默认文案就是原内联文本搬迁）。

### 6.3 群聊展示名统一为群名片优先

群聊里对她展示/落库的说话人名字此前多处按 QQ 昵称优先。现统一口径：
**群聊优先群名片（没设名片才退 QQ 昵称），私聊仍用 QQ 昵称**——覆盖历史消息行、
判官/日志中的说话人、本群身份块、打断插队消息、工具上下文（如定时投票创建者）、
用户档案与 @ 解析。回复引用里被回复者名字本来就名片优先，未变。
