## 这是什么

**大肥鱼**是一个面向 QQ 群聊场景的 AI 机器人项目。框架部分负责连接 QQ、收发 OneBot v11 事件、管理插件与两套管理界面；真正让机器人「活起来」的是 `plugins/deepseek` 插件。

它不是把一段提示词包在聊天接口外面的「AI 套壳」：插件里有完整的会话引擎、工具循环、分层记忆、心情系统、长跑任务、沙箱工作区、多模态输入和后台服务。机器人可以在多个群里长期存在，记得住人、跟得上话题、有自己的状态，也能在主人授权后连续完成一件复杂的事。

| 组成部分 | 作用 |
|---|---|
| **Tide 框架** | OneBot v11 / QQ 官方机器人连接、事件分发、插件热重载、断线重连、DearPyGui 桌面端与 Flask Web 管理面板 |
| **DeepSeek 插件** | 群聊 AI 的全部业务：触发判定、对话、工具、记忆、心情、主动行为、长跑、定时任务、工作区、多模态、MCP |
| **Web 控制台** | 设置模型与服务商、编辑每群人设和工具开关、管理记忆/MCP/提示词、查看所有后台运行记录 |
| **实时观察服务** | SSE 事件流、OBS 弹幕页、调试时间线，可实时看到 AI 从收到消息到发出的全过程 |

默认模型是 `deepseek/deepseek-flash`，也支持在 Web 控制台里配置任意 OpenAI 兼容服务商，并分别为对话、判官、摘要、记忆抽取、心情和风格学习分配模型。

## 和普通 AI 框架有什么不同

普通 AI 机器人通常是「收到消息 → 拼提示词 → 调用模型 → 发文本」。大肥鱼在这个骨架之上做了几件不太一样的事：

| 普通 AI 框架 | 大肥鱼 |
|---|---|
| 工具列表写死在代码里，加功能要改代码重启 | AI 可以自己写工具、自己写消息初筛脚本，主人验收后热上线，不需要改框架 |
| 没有记忆，或只有一个向量库 | 群友长期记忆、第一人称自我记忆、约定/待办、群摘要、群说话风格，多套记忆各司其职 |
| 只有被叫到才说话 | 每群独立心情、概率主动搭话、定时苏醒，会自己找时机开口 |
| 单轮工具调用，最多几轮 | 长跑模式可无限轮次持续工作，自动压缩上下文、强制汇报进展，任何人都能中途打断 |
| 只能处理文字 | 看图、读 PDF/Word、看视频、看屏幕坐标并点击、接 MCP 工具、操作 QQ 文件和 QQ 空间 |
| 客服腔、一条长回复 | 群聊触发过滤、分条发送、引用回复、把 @昵称 变成真 @、学习群友说话方式 |
| 安全边界靠自觉 | 风险工具主人门禁、AI 代码子进程隔离、工作区沙箱、默认只监听本机 |

### 1. AI 可以给自己造功能

插件内置了 **65 个工具**，覆盖 QQ 消息、文件、记忆、定时任务、QQ 空间等。更特别的是，AI 可以在这套工具之上继续扩展自己：

- **自定义工具（Custom Tools）**：AI 用 `custom_tool_validate` 试写并 dry-run，通过后用 `custom_tool_publish` 上线，工具名变成 `custom__<name>`，之后每轮对话都能直接调用。工具代码只在 `python -I` 短生子进程中执行，崩溃、死循环、`sys.exit` 都不会影响机器人主进程；超时会杀掉整棵进程树。发布失败会自动保留旧版本。
- **初筛脚本（Screen Scripts）**：AI 可以写「这条群消息值不值得理」的便宜判断脚本，和内置启发式一起作为多判官的第一层。脚本 5 秒超时、异常一律按「未命中」处理，不会因为脚本坏了就放行所有消息。
- **工作区脚本与监测进程**：AI 可以把脚本写进群工作区，主人授权后运行；也可以启动独立的长驻监测程序，持续盯 B 站、网页、文件等外部变化，发现事件后回调机器人的触发接口。

也就是说，很多新能力不是开发者提前写好的，而是机器人在和主人的对话里「现学现做」出来的。当然，上线和运行高风险代码的权限始终只在主人手里。

### 2. 记忆不是一个向量库，而是好几套

- **群友长期记忆**：以 QQ 用户为主体、跨群共享。CJK unigram + bigram 的本地 BM25 召回，零 embedding 依赖；重要度和时间新鲜度融合排序；相似记忆三档合并；每 5 轮异步批量抽取，不阻塞回复。每轮最多注入 6 条、约 400 字。
- **自我记忆**：关于「她」自己的经历、承诺和关系，全局一份、第一人称。每天有写入配额，支持「回忆链」沿着一条记忆继续想起相关联的事。
- **约定 / 待办 / 未完结话题**：把群里说好的事登记下来，责任人必须能解析到真实 QQ，到点主动提醒，避免「答应了又忘」。
- **群摘要**：长对话自动滚动摘要，并做节流以尽量保住模型前缀缓存。
- **群说话风格**：从全量群聊语料里学习这个群怎么说话，定期重建画像并注入系统提示词，不是千群一面的机器人腔。
- **提示词注册表**：20 个提示词分区（对话规则、富媒体、工具、上下文块、后台模型、后台触发）都可以在 Web 控制台覆盖，不写死在代码里。

### 3. 有心情，也会主动开口

- 每群一份 **心情值（0–100，基线 70，约 3 小时半衰期回落）** 和 **七种情绪（开心/踏实/甜蜜/心疼/担心/难过/吃醋，约 90 分钟半衰期）**。
- 心情由便宜模型在非静默回复后判定，按来源限制单轮变化幅度；只有显著变化、置信度足够才会注入下一轮提示词，而且同一次变化只宣布一次，每天有注入上限。
- **主动搭话**：每隔 30 分钟的概率唤醒，高峰时段（工作日 9–12、14–18）概率低、低谷时段概率高；很久没人说话会提高概率，刚聊过则降低；凌晨 1–8 点静默；机器人自己也有 20 分钟冷却。
- **定时苏醒**：即使群里一直很安静，也会按概率唤醒 AI 跑一轮完整对话（带工具、记忆、注入），模型可以选择回 `[静默]` 不说话；连续错过多次会保底触发。

### 4. 能一口气干很久，也能被随时打断

`/ai 循环 <任务>` 进入**长跑模式**：主人授权后，AI 围绕任务连续自主工作，普通对话的 50 轮工具上限对它不生效。

- 每 5 个工具轮必须在群里说一次进展，不允许长时间闷头干活；
- 上下文接近上限（默认输入预算 80%，或 40k 字符兜底）时自动压缩，只保留最近 4 轮；
- 连续 3 轮没有任何工具操作就判定空转并停止；
- 完成后必须调用 `loop_finish`，结果私聊汇报主人；
- 主人可以不开长跑，让 AI 自己提交 `loop_request` 申请，主人用 `/ai 循环 同意 <编号>` 批准；
- **任何群成员**都能用 `/ai 打断 <临时指示>` 在安全点插话调整，不需要等长跑结束；普通消息在长跑期间也会走插队通道。

### 5. 能看见，也能动手

- 入站图片直接送视觉模型（每条最多 4 张），截图自带 100px 坐标网格，AI 可以算坐标并用 `click_at` 点击。
- 支持 PDF / Word / Markdown / 文本 / 代码附件解析；扫描版 PDF 和旧 `.doc` 可渲染成图片给视觉模型看。
- 入站视频会存进工作区，AI 可用 `read_video` 看分镜 + 视觉子代理（最长 15 分钟、512 MiB，可选 ASR）；也支持 GIF 逐帧。
- 能读取合并转发、回看历史消息里的图片、下载 QQ 群文件、发图片/语音。
- 通过 **MCP**（stdio / streamable-http / SSE）接入任意外部工具；远程桌面类 MCP 配合截图点击，就能完成「打开浏览器 → 搜索 → 点按钮」这类电脑操作。

### 6. 像群友，而不是客服

- **触发过滤**：@她、回复她、叫她名字直接进对话；其他消息先由内置启发式与（可选的）AI 自制初筛脚本把关，任一放行才交给便宜模型当判官。判官失败默认不回复，不会乱接话。
- **分条发送**：长回复拆成多条短消息，带随机延迟，模拟真人打字节奏。
- **引用回复**：可开启引用原消息回复。
- **真 @**：根据群名片和昵称目录，把回复里的 `@昵称` 转成真实 QQ 艾特。
- **称呼词**：每个群可以配置她对这个群的称呼、群友叫她的名字。
- **梗指南**：自动识别群聊里的梗并注入释义，AI 也能主动查梗。
- **入群打招呼**：被拉进新群时自动发一条招呼，不受群开关和触发闸门限制。

### 7. 安全是默认值

- 写文件、删文件、发布到公共库、执行 Python/Shell、上线自定义工具/初筛脚本、@全体、发 QQ 空间、启动监测进程、批准好友申请等**风险工具默认只有主人能触发**。
- AI 生成的代码永远不在主进程执行，只在短命隔离子进程里跑；工作区禁止绝对路径、`..` 越界和符号链接逃逸。
- 外部触发服务与实时订阅服务默认只绑 `127.0.0.1`，用 Bearer token 鉴权。
- 好友申请和拉群邀请**不会自动同意**，只私聊通知主人，等主人让 AI 通过工具处理。

## 已经实现的功能

### 接入与调度

- OneBot v11 WebSocket 客户端（NapCat 等实现），以及 QQ 官方开放平台 v2 群机器人连接，`transport` 一键切换。
- 断线指数退避重连；每次重连重新初始化插件并触发 `on_start` / `on_stop`，状态落库。
- 插件热重载：卸载 → 清模块 → 重新导入；插件依赖自动安装到插件自己的 `lib/`。
- 桌面端 DearPyGui 管理界面，`-nogui` 纯控制台模式，可选 Flask Web 管理面板。
- 每群独立开关；未开启的群不进入模型、零 token；私聊另有白名单。

### 触发与回复

- @ / 回复 / 叫名字强制触发；仅 @ 模式可只响应直接对话。
- 内置启发式粗筛 / AI 自制初筛脚本任一放行 → 便宜模型判官；判官失败默认不接话。
- 分条发送、随机延迟、引用回复、真 @ 转换。
- 每群人设、思考开关（可继承全局）、称呼词、模型路由独立配置。
- 机器人入群自动打招呼。

### 工具系统

- **QQ**：发文本/图片/语音、@全体、查群成员、列举和下载群文件。
- **工作区**：列目录、读、写、追加、删除、发布到公共素材库、查看图片、看视频、文档渲染看图。
- **记忆**：查/记群友记忆、查/记自我记忆。
- **约定与时间**：登记/查询/关闭约定，当前时间。
- **定时**：登记/查询/取消定时任务，登记/启停/删除轮询。
- **QQ 空间**：发说说（仅文本）、删说说、查本地留痕（主人）。
- **请求**：查好友申请/群邀请，同意/拒绝（主人）。
- **运维**：查历史消息、查 token 用量、管理提示词注入、管理监测进程。
- **长跑**：申请长跑、结束长跑并汇报。
- **MCP**：任意 MCP server 的工具，自动命名空间化为 `mcp__<server>__<tool>`，按群开关。
- **AI 自扩展**：自定义工具 5 件套、初筛脚本 5 件套。

### 工作区与沙箱

- 每群独立目录 `workspace/<群号>/`，外加跨群共享的 `workspace/public/` 公共素材/技能库。
- 群目录默认单文件 512 KiB、总量 10 MiB；公共库单文件 4 MiB、总量 50 MiB。
- 禁止绝对路径、盘符、`..` 越界；解析后双根校验，含符号链接 realpath 检查。
- MCP 媒体文件有 TTL（默认 6 小时）和单文件上限，启动时自动清扫过期文件。

### 多模态

- 入站图片视觉理解，每条最多 4 张；截图坐标网格辅助点击。
- 附件解析：txt / md / 代码 / PDF / docx / xlsx，默认取前 4000 字。
- 扫描 PDF 和旧 `.doc` 渲染为图片，默认前 3 页、130 DPI。
- 入站视频存工作区（默认上限 50 MiB），`read_video` 做分镜 + 视觉子代理，最长 15 分钟、512 MiB，可开 ASR。
- 合并转发展开、历史消息图片回看。

### 长期记忆与自我记忆

- 群友记忆跨群共享、按 QQ 聚合；本地 BM25 召回；重要度/新鲜度融合；三档相似度合并。
- 每 5 轮异步批量抽取，单轮注入最多 6 条、约 400 字。
- 自我记忆全局第一人称，每天写入配额 8 条，召回最多 5 条、约 300 字，支持回忆链。
- 约定/待办/未完结话题登记，到点主动提醒。
- 群摘要滚动生成，带节流保护前缀缓存。
- 群风格从全量语料学习，定期重建。
- Web 控制台可查看、编辑、删除每一条记忆，也可清空某个用户或全部记忆。

### 心情与主动行为

- 每群心情值 + 七绪，读时按半衰期衰减，判定落库时重新锚定。
- 心情变化按来源限幅（真人消息 ±10、闲聊 ±5、工作 ±3、招呼 ±5），置信度和单日注入次数受限。
- 主动搭话按高峰/低谷概率、最近活跃度、自冷却和静默时段调度。
- 定时苏醒按概率唤醒，连续错过保底触发；每群可单独关闭。
- 两者都以隐藏系统通知注入，模型可以回 `[静默]` 选择不说话。

### 长跑模式

- 主人直接授权，或 AI 提交申请后主人审批。
- 无普通工具轮上限；每 5 轮强制汇报进展；上下文自动压缩；连续空转自动停。
- 完成后私聊汇报；重启时未结束会话统一标记为中断。
- 全员可用的打断通道，在安全点注入，不抢群锁。

### 定时任务与后台

- 定时任务：一次性/周期性，在指定群或私聊执行，支持提醒和主动任务。
- 自我轮询：AI 自己登记周期检查项，到点醒来看一眼。
- 外部触发 HTTP 服务：`POST /trigger`，Bearer token，按 (群, 来源) 30 秒冷却，事件异步执行。
- 监测进程：每群最多 5 个，独立 `python -I` 进程，断线/热重载不中断；通过环境变量拿到触发地址和 token。
- 后台任务工具轮上限 8 轮，避免后台运行失控烧 token。

### 实时观察

- SSE 事件流（默认 `127.0.0.1:8095`）：chat / gate / turn_start / prompt / model_round / tool_result / assistant_send / compact / notice / turn_end / meta。
- OBS 浏览器源弹幕页，透明背景。
- 调试时间线，可查看每轮完整提示词、模型原始输出和工具结果。
- 环形缓冲 1000 条，支持 `Last-Event-ID` 断点回放。

### 管理侧

- Web 控制台：全局设置、服务商与六条模型路由、群列表、每群人设/覆盖项/工具开关/心情/token 用量、记忆、MCP、提示词、后台运行记录。
- 主人指令：开关群、清空记忆、查状态、改人设、管称呼词、深度思考、忘记某人、看工具、看待办、看定时、重建风格、长跑、帮助。
- 私聊：白名单内可用，复用群会话的人设、上下文、工具和沙箱。
- 好友申请 / 群邀请：暂存并私聊通知主人，AI 不自动拍板；审批只能由主人指令 AI 调工具完成。

## 快速开始

### 1. 环境

- Python 3.12+
- Windows / Linux / macOS
- 一个 OneBot v11 实现（推荐 NapCat），或 QQ 官方机器人应用

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

首次启动时，插件加载器会按 `plugins/deepseek/requirements.txt` 把插件依赖安装到 `plugins/deepseek/lib/`（`use_plugin_venv` 默认开启）。也可以手动安装：

```bash
pip install -r plugins/deepseek/requirements.txt
```

### 3. 配置连接

首次启动会自动生成 `config.json`（已被 gitignore）。至少确认：

```json
{
  "transport": "napcat",
  "ws_address": "ws://127.0.0.1:3001",
  "token": "你的 OneBot 访问 token"
}
```

使用 QQ 官方机器人时改为 `"transport": "official"`，并填写 `official_app_id` / `official_app_secret`（也可用环境变量 `QQBOT_APP_ID` / `QQBOT_APP_SECRET`）。

### 4. 启动

```bash
python main.py          # 桌面 GUI 模式
python main.py -nogui   # 无头模式（纯控制台日志）
```

### 5. 配置 AI

推荐直接开 Web 控制台：

```json
{
  "enable_web_admin": true,
  "web_admin_host": "127.0.0.1",
  "web_admin_port": 8081,
  "web_admin_token": "请设置一个强密码"
}
```

重启后访问 `http://127.0.0.1:8081`，进入 DeepSeek 插件的「设置」页：

1. 把 `owner_qq` 设成你的 QQ 号（主人指令和风险工具都靠它鉴权）。
2. 在「模型服务商」里填写 DeepSeek 的 API Key；也可以不填，改用环境变量 `DEEPSEEK_API_KEY`。
3. 按需调整六条路由：对话、判官、摘要、记忆抽取、心情、风格学习。
4. 在群列表里打开目标群的 AI 开关，或直接在群里发 `/ai 开启`。

> API Key 只保存在被 gitignore 的 `plugins/deepseek/config.json` 或环境变量里，不要提交到仓库，也不要写进提示词或文档。

| `/ai 工具` | 查看本群生效的内置工具、MCP 工具与开关 |
| `/ai 待办` | 查看本群未结约定/待办 |

| `/ai 风格` | 立即重建本群说话风格画像 |

## 安全边界与已知限制

- **风险操作默认只认主人 QQ**：写/删文件、发布公共库、执行 Python/Shell、上线自定义工具或初筛脚本、@全体、发 QQ 空间、启动监测进程、批准好友/群邀请。上线后的自定义工具默认群内任何人都可能间接触发，可设置 `owner_only_call` 限制。
- **代码隔离不是完整安全沙箱**：AI 代码在独立子进程运行、有超时和进程树清理，但没有容器/网络隔离；自定义工具仍可访问网络。只让可信的主人来上线代码。
- **工作区沙箱防越界，但不防资源耗尽**：有单文件和总量配额，但没有 CPU/内存配额；监测进程和脚本的实际资源消耗由操作系统约束。
- **默认服务只监听本机**：`trigger_host` 和 `live_host` 默认 `127.0.0.1`；如需外网访问，请自行加反向代理、TLS 和访问控制。`trigger_token` 同时保护触发接口和 SSE。
- **Web 面板不是为公网设计的**：默认配置是关闭的；启用时请设置强 `web_admin_token`，并把 `web_admin_host` 改成 `127.0.0.1` 或放在可信反向代理后面。
- **官方机器人通道功能受限**：QQ 官方开放平台对主动消息、文件、@全体、QQ 空间等能力有平台限制；需要完整体验建议使用 NapCat / OneBot v11。
- **模型会产生不可预测的输出**：判官、心情、记忆抽取都是便宜模型的启发式判断，可能误判；重要操作始终保留主人门禁，不要把不可逆操作完全交给 AI。
- **API Key 只放配置文件或环境变量**：`config.json`、`plugins/*/config.json` 和数据库均在 gitignore 中，不要提交，也不要把 Key 贴进 issue、提示词或截图。
